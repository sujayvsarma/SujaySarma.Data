SujaySarma.Data.WinFormsUI
==========================
Sujay Sarma's Windows Forms Data-binding Helper Library. This library assists in painless data-binding a Windows Forms UI to the object entity model. This library is designed to work with my (SujaySarma.Data.*) ORM frameworks and will not work with any other ORM framework (like EF).
